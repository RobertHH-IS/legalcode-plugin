# More Legalcode Skills

These specialist skills are available from the Legalcode plugin repository but are not
automatically bundled with the 10 core plugin skills:

- `business-legal-radar-private-agent-watch`
- `legalcode-anti-gold-plating-is`
- `legalcode-docx-render`
- `legalcode-mcp-setup`

Copy or install only the additional skill directories you need. Each directory contains
its own `SKILL.md` and any required references, templates, or scripts.
